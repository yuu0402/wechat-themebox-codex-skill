# ThemeBox.dat Playbook

Use this playbook only when a target ThemeBox import or export path mentions `themebox.dat`.

## What It Is

- Treat `themebox.dat` as a private export artifact generated by ThemeBox.
- Do not reverse engineer it.
- Do not copy it from another author, sample pack, or shared repo.
- Only compare the observable package shape, filenames, dimensions, and slot behavior.

## When Import Fails

1. Confirm the release zip matches the documented package matrix.
2. Confirm `config.json`, `cover.png`, `icon.png`, and `weui_color_new.xml` exist at the expected paths.
3. Confirm the archive does not contain source junk, duplicate roots, or protected sample files.
4. If the target workflow explicitly requires `themebox.dat`, export a fresh original blank/custom theme through the current user's own ThemeBox installation.
5. Compare only the resulting file placement and allowed filenames against the working package.
6. Document the exact failure message and the device/ThemeBox version.

## Do Not

- Do not borrow `themebox.dat` from another theme.
- Do not use a receipt from a different account.
- Do not assume missing `themebox.dat` means the theme should be rebuilt from copied data.
- Do not publish a package that depends on unknown private bytes without a documented local export path.
